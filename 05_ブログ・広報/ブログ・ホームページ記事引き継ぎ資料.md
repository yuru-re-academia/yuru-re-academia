## 2. 記事作成における厳格なルール・執筆ガイドライン（確定仕様）

ユーザーからの指示・調整を経て確定した、記事作成における絶対ルールです。新プロジェクトでもこの規定をそのまま適用してください。

### ① タイトル命名規則
- **タイトルの先頭に必ず日付を入れる**：`【YYYY.MM.DD】タイトル本文`
  - *理由*: 日付をタイトル先頭に入れておくことで、CMS側の日付ソートや自動抽出、一覧表示で視認性が担保されるため。
  - *例*: `【2024.07.10】NHK総合「いろ★ドリ」生放送に出演しました`

### ② 文体トーン（公式ニュースレター調）
- **挨拶文は一切不要**: 「こんにちは！」「皆様いかがお過ごしでしょうか」などの挨拶は入れず、本題から入る。
- **感嘆符「！」の排除**: 「〜してみてくださいね！」「〜でした！」等のビックリマークは使用禁止。「〜ぜひご確認ください」「〜となりました」と落ち着いたトーンにする。
- **客観的・公式トーン**: 親しみやすさよりも「公式ニュースレター」「プレスリリース」に近い客観的な文体とする。
- **平易な言葉で「権威性」を担保**: 難しい専門用語を並べるのではなく、分かりやすい言葉を使いながらも、メディア実績（NHK、全国FM、日本海新聞、Yahoo!ニュース等）や行政・学校・大企業連携の事実を客観的に記述して権威性・信頼感を持たせる。

### ③ ターゲット・リーチ設計
- **山陰・鳥取・米子圏域**の地域シニアおよびそのご家族。
- **「シニア男性」の心理的ハードルを下げる工夫**: 運動習慣の少ない高齢男性でも気軽・安全に参加できる点に言及する。

### ④ 記事末尾の必須掲載ブロック（関連リンク・参考情報）
- 取材元、掲載メディア、登壇した学校・企業・自治体などの**正式名称、簡単な紹介、公式ホームページURL**を箇条書きで必ず掲載する。
- *例*:
  ```markdown
  【関連リンク・参考情報】
  ・NHK鳥取放送局「いろ★ドリ」公式ホームページ：https://www.nhk.jp/p/irodori/
  ・中海・宍道湖・大山圏域市長会 公式ホームページ：https://na-s-da.net/
  ```

### ⑤ メディア・画像・PDF連携
- イベントチラシ画像や取材時の写真、紹介動画URL（キョンキョン紹介ラジオの動画等）、中海健康まつり等のチラシPDFがある場合は、本文内に案内・リンクを設置する。

## 4. STUDIO CMS 自動化スクリプト資産（技術詳細）

本プロジェクト内 `/tools/studio_automation/` ディレクトリに、STUDIO CMSをChrome遠隔操作（CDP: Chrome DevTools Protocol）で下書き自動投入するためのスクリプト群が構築されています。

### 主要スクリプト構成
1. **`cdp_client.js`**:
   - WebSocket経由で起動中Chrome（`--remote-debugging-port=9222`）に接続し、DOM取得、マウス/キーボード入力、ページ遷移、スクリーンショット取得を行う中核モジュール。
2. **`batch_articles_data.js`**:
   - 上記8記事のタイトル、日付、本文段落、リンク先情報が定義された構造化データファイル。
3. **`create_all_drafts_pipeline.js` / `run_pipeline_final.js`**:
   - 記事一覧画面から「＋新規追加」をクリック → タイトル入力 → ProseMirrorエディタへ段落ごとの本文挿入 → カテゴリ「ゆるダン」選択 → 自動下書き保存（7秒待機） → 「戻る」ボタンで一覧復帰、をループ実行するパイプライン。

### 自動化運用の現状と引き継ぎ時の留意点
- STUDIOのエディタはSPA（シングルページアプリケーション）であり、DOM要素（`.title-div.main-title` や `.ProseMirror.in-cms`）の描画タイミングや「戻る」ボタンのモーダル挙動にディレイや競合が発生しやすい特性があります。
- 新プロジェクトへの移行にあたっては：
  - **選択肢A（CDP自動投入をブラッシュアップ）**: スクリプト内のセレクタ待機時間を調整して一括登録を完了させる。
  - **選択肢B（手動コピペ投入）**: 本ドキュメント（第3項）に全8記事のタイトル・本文・リンクが完全にテキスト化されているため、手動でSTUDIO管理画面に貼り付ければ10分程度で確実に全件下書き作成が完了します。

## 5. 新プロジェクト立ち上げ時の推奨ステップ

1. **新リポジトリ/プロジェクトの作成**:
   - 例: `yurudan-website-cms` や `yuru-dan-blog` などの名称でプロジェクトを立ち上げる。
2. **本ドキュメントの移行**:
   - 本ファイル（`ブログ・ホームページ記事引き継ぎ資料.md`）を新プロジェクトのルートへコピーする。
3. **スクリプト資産の移行（必要な場合）**:
   - `tools/studio_automation/` 配下のコード（`cdp_client.js`, `batch_articles_data.js`, `create_all_drafts_pipeline.js` 等）を新プロジェクトへコピーする。
4. **未登録記事のCMS下書き反映**:
   - 上記第3項の8記事がSTUDIO CMSに下書き登録されているか確認し、未登録分を投入。
5. **画像・リンクの実装・公開スケジュール策定**:
   - 各記事に紐づく画像（中海健康まつりの写真、NHK出演画像、記事切り抜き等）をSTUDIOにアップロードし、順次公開（Publish）を進める。
